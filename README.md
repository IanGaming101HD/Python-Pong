# Pong Game

Welcome to the Pong Game project, a Python application built using Pygame. This project recreates the classic Pong arcade game with simple two-player mechanics, smooth paddle movement, and basic collision physics.

## Features

* Classic Pong gameplay
* Two-player local mode
* Smooth paddle movement and ball physics
* Score tracking system
* Simple restart/game reset functionality

## Prerequisites

Before running the Pong Game, ensure you have the following:

* Python (3.8 or higher recommended)
* pip (Python package manager)
* Pygame library

## Installation

Follow these steps to get your Pong Game up and running:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/imtiazhasan07/pong-pygame.git
   cd pong-pygame
   ```

2. **Install dependencies:**
   Install Pygame using pip:

   ```bash
   pip install pygame
   ```

## Usage

To launch the Pong Game, run the following command from the project directory:

```bash id="qv92kd"
python main.py
```

(Replace `main.py` with your actual file name if different.)

### Controls

* Player 1: W (up), S (down)
* Player 2: Up Arrow (up), Down Arrow (down)
